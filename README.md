## Project Overview

An end-to-end machine learning project that predicts the presence or absence of heart disease using patient health measurements. It includes data cleaning, exploratory data analysis, preprocessing, model training, cross-validation, hyperparameter tuning, and evaluation.

## Models

- Logistic Regression
- Random Forest

## Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Joblib, Streamlit

Disclaimer: This project is for educational purposes only and must not be used for medical diagnosis or treatment decisions.
